# ADR-0002: Minimal Skills

## Decision

Start with three project skills:

1. `/bannerlord-research`
2. `/coop-architecture`
3. `/mvp-check`

## Why

Skills should encode repeatable workflows, not duplicate the entire project documentation.

Do not create a skill merely because a topic exists.

## Add another skill only when

- the workflow repeats
- the procedure is stable
- the skill reduces prompt size or mistakes
- its responsibilities are clear and non-overlapping
